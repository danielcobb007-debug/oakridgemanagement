# AUDIT CHECKLIST

## Purpose

This checklist governs reviews of:
- websites
- repositories
- AI-generated content
- investor materials
- partner materials
- deployment structure
- narrative consistency

The objective is to prevent:
- platform drift
- duplication
- ownership confusion
- governance breakdown
- inconsistent public positioning

---

# Narrative Audit

## Confirm hierarchy is consistent:

1. ORM = parent control layer
2. CEH = ORM-owned standard
3. CEH Index = ORM-owned product/data layer
4. DGE&I = deployment/reference implementation

---

## Verify materials DO NOT:
- position DGE&I as parent entity
- imply CEH ownership outside ORM
- blur governance authority
- contradict MASTER_CONTEXT.md

---

# Brand Audit

## Confirm tone is:
- institutional
- authoritative
- commercially intelligent
- scalable
- concise

---

## Reject:
- startup hype
- vague futurism
- consulting jargon
- excessive abstraction
- inconsistent naming

---

# Website Audit

## Confirm:
- navigation hierarchy is correct
- cross-links are functional
- branding is consistent
- shared assets are reused properly
- duplicate pages are avoided

---

## Verify:
- ORM links downward
- CEH links upward to ORM
- DGE&I references ORM and CEH correctly

---

# Repository Audit

## Confirm:
- files are stored in correct domains
- no duplicate systems exist
- archive structure is maintained
- governance files are current
- deployment structure follows standards

---

## Flag:
- duplicated content
- inconsistent folder structures
- scattered assets
- legacy drift
- abandoned files

---

# AI Audit

## Claude Output Review
Check for:
- structural drift
- inconsistent hierarchy
- duplicate language
- overbuilding
- uncontrolled abstraction

---

## Codex Audit Review
Check for:
- broken references
- deployment risks
- architecture inconsistencies
- governance violations
- repo fragmentation

---

# Deployment Audit

## Before deployment confirm:
- governance review completed
- hierarchy verified
- links tested
- assets validated
- production approval granted

---

# Decision Audit

## Major changes must be logged in:
- DECISIONS.md
- SESSION_LOG.md

---

# Final Governance Rule

No deployment, partner material, website update, or AI-generated output should violate the ORM platform hierarchy or governance structure.
