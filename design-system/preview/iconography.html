Principle

ORM uses an almost-iconless visual system. No emoji. No icon fonts. No hand-drawn SVG. Iconography is typographic glyphs set in IBM Plex Mono at body size. If a glyph and a short label can't do the job, substitute thinnest-stroke Lucide icons at the same optical weight as adjacent text — and flag the substitution.
