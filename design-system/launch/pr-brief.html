§ 07Body

PR description (paste into GitHub)

Summary

Adds the ORM design system v1 as new surfaces under ui_kits/. Two production-ready kits (ORM Public, DGE&I Investor Portal) plus reserved CEH technical components. No changes to the currently-deployed root index.html, netlify.toml, or any governance / operations docs. CEH framed as a developing methodology framework throughout — methodology preview, subject to validation, not a certified public index.

What this PR adds

  • ui_kits/public-site/ — institutional warm-stone ORM homepage (Source Serif 4 / Inter / IBM Plex Mono · navy / bronze / forest / charcoal). 10 React components.
  • ui_kits/investor-portal/ — DGE&I restricted partner portal. Data-room aesthetic, ORM access-layer ribbon, 9 React components.
  • colors_and_type.css — shared design tokens for both surfaces.
  • preview/ — 22 design-system review cards (documentation, not pages).
  • review/ — consolidated review snapshot with screenshots.
  • launch/ — readiness package + this PR briefing.
  • assets/orm-favicon.svg, assets/dg-favicon.svg, assets/dg-logo.svg — new SVG assets.

What this PR does not touch

  • Root index.html (current deployed site).
  • netlify.toml (existing redirect + Identity gate rules).
  • assets/css/shared.css + assets/css/investor-theme.css (legacy Bloomberg-dark, preserved as reference; not loaded by either new kit).
  • assets/js/nav.js.
  • 00_Governance/, 10_Operations/, 04_DGEI_Relationship/ and any other documentation directories.

CEH language pass

Per direction (CEH page deferred until methodology v1.0 is locked), every CEH reference on the ORM public site was softened. Stage chips: "Published v1.0" → "Methodology preview"; "Live" → "Internal draft". Body copy across ActiveWorkstreams.jsx, OperatingDomains.jsx, OperatingPerimeter.jsx, FounderCard.jsx, Footer.jsx framed as: developing framework · methodology preview · subject to validation · not a certified public index · not an externally adopted benchmark unless separately established.

Hard rules preserved

  • No Georgia Benefits Group on ORM public or investor portal (audited — zero matches).
  • No "fund / invest now / guaranteed return / registered adviser" language.
  • DGE&I monogram only on DGE&I surfaces.
  • CEH technical (dark) surface stays out of the ORM public site.

Review checklist (for staging deploy preview)

  • Visit /ui_kits/public-site/ on the deploy-preview URL — verify warm-stone institutional aesthetic, all 10 sections render, CEH language reads as a developing framework.
  • Visit /ui_kits/investor-portal/ — verify ORM access ribbon, DGE&I masthead, data-room cards.
  • Open /review/ and /launch/ as snapshot artifacts.
  • Confirm root / still serves the existing deployed site unchanged.
  • Confirm /investor/platform/ Netlify Identity gate still enforces (this PR does not change the gate).

Out of scope for this PR (next steps)

  • Counsel review of Is/Is Not + footer + portal disclosures.
  • Cutover: replacing root index.html with the new homepage (separate explicit PR).
  • Routing /investor/platform/ to the new investor portal.
  • Real Site Portfolio numbers + real Data Room index.
  • Strategic Conversations form backend.
  • CEH technical page (deferred).
